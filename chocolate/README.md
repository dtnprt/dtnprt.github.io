# Website (GitHub Pages: https://dtnprt.github.io/chocolate/)

```
index.html          landing page: links to the Web Config and the custom firmware page, demo video (generated)
firmware/index.html custom firmware page: release notes, downloads, how to flash (generated)
firmware/*.fwsc     downloads (generated by ../tools/make_site.py, git-ignored: vendor code)
media/              demo video (AV1 + VP9 WebM, no audio/metadata) + poster
webconfig/          Chocolate Plus Web Config (source; also embedded by ../android/build_apk.py)
start.bat           serve this folder on http://localhost:8002
```

- Regenerate the release page: `python -I tools/make_site.py` (new release: edit `RELEASES` / `HISTORY` there).
- Deploy: automatic when `main` is pushed to `origin` (hook `tools/hooks/pre-push`, enabled with
  `git config core.hooksPath tools/hooks`), or manually `python -I tools/deploy_site.py [--dry-run]`.
  It replaces the folder `chocolate/` in the Pages repo (remote `pages`) with this folder and pushes.
