    Known files

    These files are in the file menu, and the terminal app follows the current file when it is a cloud (WebDAV) file or listed here. The icon shows where a file lives (cloud, git folder, local); the lock whether it is stored encrypted. Each folder keeps a hidden .todotxt.cfg that says what is encrypted there, so single files can stay readable for other apps.

    Known folders

    A folder with a hidden .todo.txt folder is a known folder. Its settings (what is encrypted), notes and images live there, also on a WebDAV server.

    Encryption experimental

    Experimental. This feature is new and has not been reviewed or tested widely. Keep a backup of your files (File → Backup as .zip…) before you switch it on, and do not rely on it for highly sensitive data. Encrypted files can no longer be read by other todo.txt apps, editors or scripts – only by this app (web, desktop, terminal), which all share the format. Lists, notes and the WebDAV offline cache are written encrypted, so a git remote or a WebDAV server only ever sees ciphertext. Pasted images are not encrypted. Keep the password safe: without it the files cannot be read.
