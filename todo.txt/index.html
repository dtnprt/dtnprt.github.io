Your tasks. One text file.
Three apps.

A fast, keyboard-friendly client for the todo.txt format – in your browser, as a desktop app and in the terminal. No account, no cloud, no lock-in: everything lives in a plain todo.txt you can edit with any editor.

Open the web app View on GitHub Install

Small file, big comfort

The format stays exactly what it is – one task per line. The apps add everything you would otherwise do by hand.

⌨️

One input for everything

Add tasks, or press / to search. Live syntax highlighting and autocomplete for (A) priorities, +projects and @contexts.

📅

Smart dates

Write due:tomorrow, due:+3d, due:15.03. or due:next week – it becomes due:YYYY-MM-DD. A calendar pops up while you type.

🚦

Due colours

Overdue, due today and due soon are colour-coded in the list, the terminal and the CLI alike.

📝

Notes

Type note: and write as much as you like. The text lives in notes/NAME.txt next to your list – the task line stays short.

🌳

Sub-entries

Lines with - to ---- after the date become sub-entries. Sorting keeps groups together; paste an outline and it is split correctly.

📋

Smart paste

Paste several lines: add each as an entry, as an entry with sub-entries, or as one entry with the rest as a note.

🗂️

Folders

Use a whole folder of lists and switch between them. Move projects (with their sub-entries) from one file to another.

🔄

Git & WebDAV sync

Opt-in git sync (pull on start, commit and push after every change) or a WebDAV file – with an offline cache and three-way merge.

🎨

50+ themes

Nord, Dracula, Catppuccin, Solarized, Rosé Pine, Tokyo Night, a retro Cupertino 9 and X, Terminal and Accessibility families … Themes are plain CSS files – write your own.

↩️

Undo, drag & drop, archive

Undo and redo everywhere, re-prioritise by dragging, archive finished tasks to done.txt.

🔁

Always in sync with the file

Edit the file in your editor, with Syncthing or git – the apps notice and reload it.

🔒

Private by design

Nothing is uploaded. Optional, experimental AES-256-GCM encryption of lists, notes and images (git and WebDAV only see ciphertext; other todo.txt apps can then no longer read the files), password in your OS keyring, optional Windows Hello. Hide the window from screenshots and screen sharing.

🗜️

Zip backups

One click (or todo --backup) writes a .zip of lists, notes and images – automatically before archiving done tasks. Encrypted files stay encrypted.

Dates without friction

Type due and a calendar follows what you write: year, month, day. Or just type due:tomorrow – a space turns it into a real date.

Paste a plan, get a project

Paste several lines and decide how they are added. Outline-style lists with dashes become an entry with sub-entries – or one entry with the details as a note.

Light, dark – or minimal

The default look follows your system. F11 switches to minimal mode: just the list. The menu bar slides in when you move the mouse to the top, the input when you reach for the bottom.

Three clients, one feature set

All clients read and write the same file and follow each other: start a task in the terminal, finish it in the browser.

🌐 Web

Client-only single page app. Vanilla JS, no build step, no dependencies. Works best in Chrome and Edge, where it can open and save files in place – or keep your lists right in the browser (Browser storage, no file access needed).

Open the web app

🖥️ Desktop

The web app in a Tauri window with native file dialogs, auto save, several remembered files, folder mode, git, WebDAV, a frameless window, always-on-top and your own themes.

cargo install tauri-cli --version "^2"
cd src-tauri
cargo tauri build

⬛ Terminal

todo is an interactive TUI and a scriptable command line, written in Rust.

cargo install --path cli

todo buy milk @shop due:tomorrow
todo -l +Home @phone
todo -x 3          # toggle done
todo -p 3 A        # priority
todo -u 3 call the bank   # sub-entry

Prerequisites: the Rust toolchain (and the Tauri prerequisites for the desktop app). The web app needs nothing but a browser.

Just the todo.txt format

Priorities, dates, projects, contexts and key:value tags – as defined by the todo.txt project. The parser is lenient and never rewrites what it does not understand.

(A) 2026-11-12 Fix login bug +website @work due:2026-11-13
(B) 2026-11-09 Plan the team offsite +team note:Note-1
2026-11-09 - Book a venue +team
2026-11-09 -- Compare three offers
(C) Call the dentist @phone due:2026-11-16
x 2026-11-12 2026-11-10 Renew passport +life
/search (Esc returns to adding)
F2next sort order
F3show / hide completed
F4show / hide the sidebar
F5archive done tasks
F11minimal mode
Ctrl+Zundo
F1all shortcuts

Sub-entries and note: are conventions of this app: a dash prefix after the dates marks a sub-entry, note:NAME points to notes/NAME.txt. Other todo.txt tools simply see ordinary words.

Make it yours

A theme is one self-contained CSS file with a handful of colour tokens. The desktop app ships over fifty, and anything in ~/.todo.txt/themes/ shows up in the settings.

Sync it your way

todo.txt is a file, so you already have many options. The apps add two built-in ones – both strictly opt-in.

Git

Keep a folder of lists in a repository. Pull on start, commit and push after every change, or sync manually. Without a .todo-git.cfg nothing automatic ever happens.

todo -f ~/lists --git-init
todo --git-auto on

WebDAV

Open a file on Nextcloud or any WebDAV server. Passwords are kept in the OS keyring, conflicts are detected with ETags, and an offline cache with a three-way merge keeps you working without a connection.

Anything else

Syncthing, Dropbox, a network share: the apps reload the file when it changes on disk.
