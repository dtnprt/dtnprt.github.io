# todo.txt website

Static site for https://dtnprt.github.io/todo.txt (plain HTML/CSS, no build step).

- `index.html`, `style.css`, `img/` – the landing page and its screenshots
- `app/` – a copy of the web app from the todo.txt repository (`public-repo/web`, without tests), so visitors can try it in the browser. Refresh it with: copy `*.js`, `*.html`, `*.css` and `vendor/` from `web/` over it.
