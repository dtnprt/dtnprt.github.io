    Backup all presets

    Reads every preset slot from the device and saves them in one ZIP file with one .prst file per preset (e.g. presets/A02-1-Juicy Fusion.prst) – the same format the Hotone software exports, so single presets can also be imported there. List a backup with python tools/ampero_preset.py decode <backup>.zip. Takes about 3 minutes.

    Close the Hotone Ampero software first – if it runs in the background, it talks to the pedal at the same time and answers get mixed up.
    The pedal loads every preset while it is read (the display switches through them, the sound changes). Save unsaved edits on the pedal first – they are lost. Stored presets are not changed, and the preset that was active before is selected again at the end.

    Live capture only listens and sends nothing. While the app is connected it shows the app's own traffic (both directions); otherwise it listens to the selected input – the browser then sees only what the pedal sends (its answers, also to the Hotone software, and forwarded set commands), not the Hotone software's requests. For both directions open a Wireshark/USBPcap .pcapng.
    Probe – ask the pedal for every known command (read-only)
    Asks the pedal for all ~180 command codes of the firmware's command table (like the Hotone software asks, kind 0x11) and records the answers – system commands (save, connect …), preset dump/write and chain-template selection are skipped. Then change one setting on the pedal and probe again: the codes and bytes that changed are highlighted. Takes about 1–2 minutes.
